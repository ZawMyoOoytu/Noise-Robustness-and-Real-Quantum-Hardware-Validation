# Noise-Robustness-and-Real-Quantum-Hardware-Validation

Research implementation for evaluating a Variational Quantum Classifier (VQC) under ideal simulation, controlled noise models, and real quantum hardware execution.

## Experimental Conditions

- Ideal Simulation
- Bit Flip Noise
- Phase Flip Noise
- Depolarizing Noise
- Readout Noise
- IBM Quantum Hardware

## Workflow

1. Classical preprocessing and baselines
2. Quantum feature encoding
3. VQC training
4. Ideal simulation
5. Noisy simulation
6. Noise robustness sweep
7. Real quantum hardware validation

## Repository

The repository contains the executed Jupyter notebooks and experimental results required to reproduce the study.

## Security

No API keys, access tokens, passwords, or private credentials are included. IBM Quantum credentials must be configured locally and never committed to Git.
